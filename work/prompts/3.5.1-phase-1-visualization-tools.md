# Task 3.5: Develop Visualization Tools for Protocols

## Phase 1 Specification: Basic Diagram Rendering & Integration

### 1. Overview
This phase establishes a minimal, reliable foundation for embedding protocol
visualizations in generated documentation. We will:

- Integrate a single, Rust-native diagram macro crate.
- Support in-place rendering in `rustdoc` and mdBook.
- Deliver examples and a user guide.

### 2. Phase 1 Objectives

- Add and configure the `simple-mermaid` crate for doc-comment macros.
- Demonstrate `#[doc = mermaid!(…)]` in a minimal Rust example.
- Configure mdBook to preprocess and render Mermaid fences.
- Produce a user-facing guide with code snippets for both integration paths.

### 3. Scope & Deliverables

- **Dependencies**
  - `simple-mermaid` (Rust crate) for in-doc SVG embedding.
  - `mdbook-mermaid` (preprocessor) for rendering fenced blocks in mdBook.

- **Artifacts**
  1. Updated `Cargo.toml` with a `simple-mermaid` entry.
  2. `examples/protocol_viz.rs` demonstrating a generated protocol + doc-comment.
  3. `docs/book.toml` updated with a `[preprocessor.mermaid]` section.
  4. New guide at `docs/protocol-viz.md` covering both workflows.

### 4. Detailed Specification

#### 4.1 simple-mermaid Integration

1. Add to workspace `Cargo.toml`:
   ```toml
   [dependencies]
   simple-mermaid = "0.1"
   ```
2. In `examples/protocol_viz.rs`:
   - Use the existing derive macro to define a tiny protocol.
   - Under the generated impl, add:
     ```rust
     #[doc = mermaid!(
       r#"sequenceDiagram
         Alice->>Bob: Hello!
         Bob-->>Alice: Hi!"#
     )]
     ```
3. Verify that `cargo doc` inlines the SVG diagram.

#### 4.2 mdBook Configuration

1. In `docs/book.toml`:
   ```toml
   [preprocessor.mermaid]
   command = "mdbook-mermaid"
   ```
2. In `docs/protocol-viz.md` (or other docs):
   ```markdown
   ```mermaid
   sequenceDiagram
     A->>B: Msg1
     B-->>A: Msg2
   ```
   ```
3. Run `mdbook build` and confirm that Mermaid fences render inline as SVG.

#### 4.3 User Guide (`docs/protocol-viz.md`)

Sections:

1. **Prerequisites**: installing `simple-mermaid` and `mdbook-mermaid`.
2. **Rustdoc example**: `#[doc = mermaid!(…)]` snippet in code.
3. **mdBook example**: fenced ```mermaid``` block.
4. **Tips**: SVG vs PNG, caching, CI checks.
