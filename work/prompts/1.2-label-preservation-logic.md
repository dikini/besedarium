```markdown
## Label Transformation System

### Core Concepts

The label transformation system provides type-level operations for managing
protocol labels in session types. Labels are preserved and transformed
according to these rules:

1. **Choice/Offer Duality**: Labels are preserved across dual constructs
2. **Parallel Composition**: Labels from both branches are combined
3. **Recursion**: Labels within recursive protocols are preserved
4. **Projection**: Role-specific labels are extracted during projection

### Type-Level Operations

- `TMap<F>`: Transform labels using function F
- `TCollect<Role>`: Collect all labels accessible to Role
- `TFilter<P>`: Filter labels based on predicate P
- `LabelPreservation<P, Q>`: Verify P and Q have compatible labels
- `LabelComposition<P, Q>`: Verify P and Q can be composed
```
