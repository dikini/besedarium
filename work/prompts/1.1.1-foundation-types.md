**Implementation**:

/// Communication metadata for precise channel and message identification
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct CommMetadata<C: ChanId, L: MsgLbl> {
    pub chan_id: C,
    pub msg_lbl: L,
}

impl<C: ChanId, L: MsgLbl> CommMetadata<C, L> {
    pub fn new(chan_id: C, msg_lbl: L) -> Self {
        Self { chan_id, msg_lbl }

**Key Points**:
- `CommMetadata` is parameterized by channel ID and message label types
- Both fields are public for direct access
- Implements standard derives for usability

## Debugging Guide

### Common Issues and Solutions

1. **Trait bound conflicts**:
   - Issue: Existing code doesn't satisfy new trait bounds
   - Solution: Add trait implementations to existing types

2. **Import/module issues**:
   - Issue: `cargo check` fails with "not found in this scope"
   - Solution: Verify module declarations and re-exports in `lib.rs`

3. **Lifetime issues**:
   - Issue: Compiler errors about lifetimes in trait bounds
   - Solution: All foundation traits require `'static`, ensure implementing types satisfy this

4. **Hash/Eq implementation conflicts**:
   - Issue: Derive conflicts with existing manual implementations
   - Solution: Remove manual implementations that conflict with derives

### Validation Steps

1. **Check trait coherence**: Ensure no overlapping implementations
2. **Verify Send/Sync**: All types must be thread-safe for protocol usage
3. **Test generic usage**: Create generic functions using the traits to ensure they work as expected
