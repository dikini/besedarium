# Task 3.5: Develop Visualization Tools for Protocols

## Phase 1 Visualisation foundations ✅ COMPLETED

Phase 1 establishes the foundation for embedding protocol visualizations directly into our
Rust documentation. Key outcomes:

- Integrate the `simple-mermaid` crate for doc-comment SVG rendering.
- Provide a working Rust example (`examples/protocol_viz.rs`) showing `#[doc = mermaid!(…)]`.
- Configure mdBook (`docs/book.toml`) with `mdbook-mermaid` to render fenced ```mermaid``` blocks.
- Deliver a user guide (`docs/protocol-viz.md`) covering both rustdoc and mdBook workflows.

## Phase 2 Automatic Diagram Generation

Phase 2 builds on Phase 1's foundation to implement automatic diagram generation directly from 
protocol type definitions using derive macros. Key innovations:

- **Derive Macro Integration**: Extend existing derive macro infrastructure with `#[derive(GenerateDiagram)]`
- **Type-Level Analysis**: Extract protocol flow from Rust type system using protocol introspection
- **Automatic Documentation**: Generate Mermaid diagrams automatically in doc comments
- **API Compatibility**: Work seamlessly with existing protocol examples and definitions
