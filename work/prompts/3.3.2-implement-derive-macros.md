# Task 3.3.2: Implement Simple Derive Macros

## Objective

Implement basic derive macros that automatically generate trait implementations for common protocol patterns, focusing on `#[derive(Role)]`, `#[derive(Message)]`, and related derive functionality.

## Background

Building on the enhanced declarative macro infrastructure from Task 3.3.1, this task introduces derive macros to further reduce boilerplate code. Derive macros provide automatic trait implementations through the `#[derive(...)]` attribute, making protocol definition more ergonomic.

This task requires procedural macro capabilities and will create a new `proc-macro` crate dependency for Besedarium.

## Requirements

### 1. Procedural Macro Crate Setup

- Create a separate proc-macro crate: `besedarium-macros`
- Set up proper `Cargo.toml` configuration for proc-macros
- Establish re-export structure from main `besedarium` crate
- Ensure compatibility with stable Rust

### 2. Core Derive Macros

Implement these derive macros:

- `#[derive(Role)]` - Automatic `Role` trait implementation
- `#[derive(Message)]` - Automatic `Message` trait implementation  
- `#[derive(ChanId)]` - Automatic `ChanId` trait implementation
- `#[derive(MsgLbl)]` - Automatic `MsgLbl` trait implementation

### 3. Derive Macro Attributes

Support customization through attributes:

- `#[role(name = "CustomName")]` - Custom role display name
- `#[message(metadata = "Custom")]` - Custom metadata type
- `#[chan_id(name = "CustomChannel")]` - Custom channel identifier
- `#[msg_lbl(name = "CustomLabel")]` - Custom message label

### Phase 2: Implement `#[derive(Role)]`

In `besedarium-macros/src/lib.rs`:

```rust
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, DeriveInput, Data, Fields, Meta, NestedMeta};

#[proc_macro_derive(Role, attributes(role))]
pub fn derive_role(input: TokenStream) -> TokenStream {
    let input = parse_macro_input!(input as DeriveInput);
    
    let name = &input.ident;
    let (impl_generics, ty_generics, where_clause) = input.generics.split_for_impl();
    
    // Parse role attributes
    let display_name = parse_role_attributes(&input.attrs)
        .unwrap_or_else(|| name.to_string());
    
    // Verify this is a struct (roles should be unit structs)
    match input.data {
        Data::Struct(ref data) => {
            match data.fields {
                Fields::Unit => {
                    // Good - unit struct
                }
                _ => {
                    return syn::Error::new_spanned(
                        name,
                        "Role derive only supports unit structs"
                    ).to_compile_error().into();
                }
            }
        }
        _ => {
            return syn::Error::new_spanned(
                name,
                "Role derive only supports structs"
            ).to_compile_error().into();
        }
    }
    
    let expanded = quote! {
        impl #impl_generics ::besedarium::protocol::foundation::Role for #name #ty_generics #where_clause {
            type Protocol = (); // To be set during protocol definition
        }
        
        impl #impl_generics ::std::fmt::Display for #name #ty_generics #where_clause {
            fn fmt(&self, f: &mut ::std::fmt::Formatter<'_>) -> ::std::fmt::Result {
                write!(f, #display_name)
            }
        }
        
        impl #impl_generics ::std::fmt::Debug for #name #ty_generics #where_clause {
            fn fmt(&self, f: &mut ::std::fmt::Formatter<'_>) -> ::std::fmt::Result {
                f.debug_struct(#display_name).finish()
            }
        }
        
        impl #impl_generics ::std::clone::Clone for #name #ty_generics #where_clause {
            fn clone(&self) -> Self {
                *self
            }
        }
        
        impl #impl_generics ::std::marker::Copy for #name #ty_generics #where_clause {}
        
        impl #impl_generics ::std::cmp::PartialEq for #name #ty_generics #where_clause {
            fn eq(&self, _other: &Self) -> bool {
                true // Unit structs are always equal
            }
        }
        
        impl #impl_generics ::std::cmp::Eq for #name #ty_generics #where_clause {}
        
        impl #impl_generics ::std::hash::Hash for #name #ty_generics #where_clause {
            fn hash<H: ::std::hash::Hasher>(&self, state: &mut H) {
                #display_name.hash(state);
            }
        }
    };
    
    TokenStream::from(expanded)
}

fn parse_role_attributes(attrs: &[syn::Attribute]) -> Option<String> {
    for attr in attrs {
        if attr.path.is_ident("role") {
            if let Ok(Meta::List(meta_list)) = attr.parse_meta() {
                for nested in meta_list.nested {
                    if let NestedMeta::Meta(Meta::NameValue(nv)) = nested {
                        if nv.path.is_ident("name") {
                            if let syn::Lit::Str(lit_str) = nv.lit {
                                return Some(lit_str.value());
                            }
                        }
                    }
                }
            }
        }
    }
    None
}
```

### Phase 3: Implement `#[derive(Message)]`

```rust
#[proc_macro_derive(Message, attributes(message))]
pub fn derive_message(input: TokenStream) -> TokenStream {
    let input = parse_macro_input!(input as DeriveInput);
    
    let name = &input.ident;
    let (impl_generics, ty_generics, where_clause) = input.generics.split_for_impl();
    
    // Parse message attributes
    let metadata_type = parse_message_attributes(&input.attrs)
        .unwrap_or_else(|| quote!(::besedarium::protocol::foundation::StandardMetadata));
    
    let expanded = quote! {
        impl #impl_generics ::besedarium::protocol::foundation::Message for #name #ty_generics #where_clause {
            type Metadata = #metadata_type;
        }
        
        impl #impl_generics ::std::fmt::Display for #name #ty_generics #where_clause {
            fn fmt(&self, f: &mut ::std::fmt::Formatter<'_>) -> ::std::fmt::Result {
                write!(f, stringify!(#name))
            }
        }
    };
    
    TokenStream::from(expanded)
}

fn parse_message_attributes(attrs: &[syn::Attribute]) -> Option<proc_macro2::TokenStream> {
    for attr in attrs {
        if attr.path.is_ident("message") {
            if let Ok(Meta::List(meta_list)) = attr.parse_meta() {
                for nested in meta_list.nested {
                    if let NestedMeta::Meta(Meta::NameValue(nv)) = nested {
                        if nv.path.is_ident("metadata") {
                            if let syn::Lit::Str(lit_str) = nv.lit {
                                let metadata_type = lit_str.value();
                                // Convert string to TokenStream - simplified for common cases
                                return match metadata_type.as_str() {
                                    "Standard" => Some(quote!(::besedarium::protocol::foundation::StandardMetadata)),
                                    "Custom" => Some(quote!(::besedarium::protocol::foundation::CustomMetadata)),
                                    "None" => Some(quote!(())),
                                    _ => {
                                        // Try to parse as a type path
                                        let tokens: proc_macro2::TokenStream = metadata_type.parse().ok()?;
                                        Some(tokens)
                                    }
                                };
                            }
                        }
                    }
                }
            }
        }
    }
    None
}
```
