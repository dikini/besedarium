# Task 3.3.1: Enhance Declarative Macros Infrastructure

## Objective

Expand the existing declarative macro infrastructure in `src/macros.rs` to provide better support for common protocol patterns and lay the foundation for more advanced macro development.

## Background

The current `src/macros.rs` contains a basic `impl_traits_for_label!` macro for implementing traits on label types. This task builds upon this foundation to create more comprehensive declarative macros that reduce boilerplate and improve developer experience.

## Requirements

### 1. Enhance Existing Macro Infrastructure

- Expand `impl_traits_for_label!` macro with better error handling
- Add documentation and examples for existing macros
- Ensure compatibility with the current foundation types

### 2. Add Protocol Definition Macros

Implement new declarative macros:

- `define_role!` - Simplify role type definition with automatic trait implementations
- `define_message!` - Create message types with automatic trait implementations
- `define_protocol!` - Basic protocol construction helper
- `messages!` - Batch message type definition

### 3. Integration with Foundation Types

Ensure all macros work seamlessly with:

- `Role`, `Message`, `GlobalProtocol`, `LocalProtocol` traits
- `CommMetadata` infrastructure
- `SupportsActionIO` trait system
- Existing type-level patterns

## Implementation Guide

### Phase 1: Expand Current Infrastructure

Start by enhancing the existing macro in `src/macros.rs`:

```rust
// Enhanced version of existing macro
macro_rules! impl_traits_for_label {
    ($label_type:ty) => {
        impl crate::protocol::foundation::MsgLbl for $label_type {
            fn label_name() -> &'static str {
                stringify!($label_type)
            }
        }
        
        impl std::fmt::Display for $label_type {
            fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
                write!(f, "{}", Self::label_name())
            }
        }
    };
    
    // Add variant with custom label name
    ($label_type:ty, $name:literal) => {
        impl crate::protocol::foundation::MsgLbl for $label_type {
            fn label_name() -> &'static str {
                $name

        }

                write!(f, "{}", Self::label_name())

        }
    };
}
```

### Phase 2: Add Role Definition Macro

```rust
macro_rules! define_role {
    ($role_name:ident) => {
        #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
        pub struct $role_name;
        
        impl crate::protocol::foundation::Role for $role_name {
            type Protocol = (); // Will be set during protocol definition
        }
        
        impl std::fmt::Display for $role_name {
            fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
                write!(f, stringify!($role_name))
            }
        }
    };
    
    // Variant with custom display name
    ($role_name:ident, $display:literal) => {
        #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
        pub struct $role_name;
        
        impl crate::protocol::foundation::Role for $role_name {
            type Protocol = (); // Will be set during protocol definition
        }

            fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
                write!(f, $display)
            }
        }
    };
}
```

### Phase 3: Add Message Definition Macro

```rust
macro_rules! define_message {
    ($msg_name:ident { $($field:ident: $field_type:ty),* }) => {
        #[derive(Debug, Clone, PartialEq)]
        pub struct $msg_name {
            $(pub $field: $field_type,)*
        }
        
        impl crate::protocol::foundation::Message for $msg_name {
            type Metadata = crate::protocol::foundation::StandardMetadata;
        }
        
        impl std::fmt::Display for $msg_name {
            fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
                write!(f, stringify!($msg_name))
            }
        }
    };
    
    // Simple message without fields
    ($msg_name:ident) => {
        #[derive(Debug, Clone, Copy, PartialEq, Eq)]
        pub struct $msg_name;
        
        impl crate::protocol::foundation::Message for $msg_name {
            type Metadata = crate::protocol::foundation::StandardMetadata;
        }
        
        impl std::fmt::Display for $msg_name {
            fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
                write!(f, stringify!($msg_name))
            }
        }
    };
}
```

### Phase 4: Add Batch Message Definition

```rust
macro_rules! messages {
    ($($msg_name:ident),* $(,)?) => {
        $(
            define_message!($msg_name);
        )*
    };
    
    ($($msg_name:ident { $($field:ident: $field_type:ty),* }),* $(,)?) => {
        $(
            define_message!($msg_name { $($field: $field_type),* });
        )*
    };
}
```

### Phase 5: Add Basic Protocol Construction Helper

```rust
macro_rules! define_protocol {
    ($protocol_name:ident, $roles:ty, $global:ty) => {
        pub struct $protocol_name;
        
        impl crate::protocol::foundation::GlobalProtocol for $protocol_name {
            type Roles = $roles;
            type Global = $global;
        }
    };
}
```

## Testing Strategy

### Unit Tests

Create comprehensive tests for each macro:

```rust
#[cfg(test)]
mod tests {
    use super::*;
    
    #[test]
    fn test_define_role_macro() {
        define_role!(TestRole);
        
        let role = TestRole;
        assert_eq!(format!("{}", role), "TestRole");
        
        // Test trait implementation
        use crate::protocol::foundation::Role;
        let _: &dyn Role = &role;
    }
    
    #[test]
    fn test_define_message_macro() {
        define_message!(TestMessage { data: String, id: u32 });
        
        let msg = TestMessage {
            data: "test".to_string(),
            id: 42,
        };
        
        assert_eq!(format!("{}", msg), "TestMessage");
        
        // Test trait implementation
        use crate::protocol::foundation::Message;
        let _: &dyn Message = &msg;
    }
    
    #[test]
    fn test_messages_batch_macro() {
        messages!(Msg1, Msg2, Msg3);
        
        let msg1 = Msg1;
        let msg2 = Msg2;
        let msg3 = Msg3;
        
        assert_eq!(format!("{}", msg1), "Msg1");
        assert_eq!(format!("{}", msg2), "Msg2");
        assert_eq!(format!("{}", msg3), "Msg3");
    }
}
```

### Integration Tests

Test macro-generated types with existing infrastructure:

```rust
#[cfg(test)]
mod integration_tests {
    use super::*;
    use crate::protocol::foundation::*;
    
    #[test]
    fn test_macro_generated_types_with_foundation() {
        define_role!(Client);
        define_role!(Server);
        define_message!(LoginRequest { username: String });
        define_message!(LoginResponse { success: bool });
        
        // Test that generated types work with foundation infrastructure
        let client = Client;
        let server = Server;
        let login_req = LoginRequest {
            username: "test_user".to_string(),
        };
        let login_resp = LoginResponse { success: true };
        
        // Verify trait implementations work
        assert!(format!("{}", client).len() > 0);
        assert!(format!("{}", server).len() > 0);
        assert!(format!("{}", login_req).len() > 0);
        assert!(format!("{}", login_resp).len() > 0);
    }
}
```
