# Task 3.3.5: Implement Dual Protocol Generation Integration

## Objective

Integrate automatic dual protocol generation into the macro DSL system, leveraging existing dual generation research and the `IsDual` trait infrastructure to automatically generate dual protocols from `#[protocol]` specifications.

## Background

The Besedarium library has extensive research on dual protocol generation (documented in `work/dual_generation_research.md`) and a robust `IsDual` trait system. This task integrates automatic dual generation into the macro DSL, allowing users to specify `generate_dual = true` in protocol attributes and automatically receive both the protocol and its dual.

This capability is essential for comprehensive session type systems, where every protocol should have a well-defined dual that maintains type safety and communication correctness.

## Requirements

### 1. Automatic Dual Generation

Extend the `#[protocol]` macro to support automatic dual generation:

```rust
#[protocol(generate_dual = true)]
/// protocol ClientServer {
///     roles: Client, Server;
///     Client -> Server: Request(data: String);
///     Server -> Client: Response(result: String);
/// }
struct ClientServer;

// Should automatically generate:
// - ClientServerProtocol (original)
// - ServerClientProtocol (dual)
// - IsDual implementations proving duality
```

### 2. Dual-Aware Code Generation

Generate code that includes:

- Original protocol types and implementations
- Dual protocol types with swapped roles
- `IsDual` trait implementations proving correctness
- Documentation indicating dual relationships
- Validation that duals are correctly formed

### 3. Integration with Existing Dual Infrastructure

Leverage existing components:

- `IsDual` trait from `src/protocol/duality.rs`
- Dual computation patterns from research
- Type-level dual verification
- Existing dual generation algorithms

### 4. Enhanced Protocol Attributes

Support dual-related configuration:

```rust
#[protocol(
    generate_dual = true,
    dual_name = "CustomDualName",
    verify_duality = true,
    dual_documentation = true
)]
```

```rust
#[derive(Debug, Default)]
pub struct ProtocolAttributes {
    // Existing attributes
    pub io_type: Option<String>,
    pub metadata_type: Option<String>,
    pub buffer_size: Option<usize>,
    pub timeout_ms: Option<u64>,
    
    // New dual generation attributes
    pub generate_dual: bool,
    pub dual_name: Option<String>,
    pub verify_duality: bool,
    pub dual_documentation: bool,
}

fn parse_protocol_args(args: TokenStream) -> ProtocolAttributes {
    let mut attrs = ProtocolAttributes::default();
    
    if args.is_empty() {
        return attrs;
    }
    
    let parser = syn::punctuated::Punctuated::<syn::Meta, syn::Token![,]>::parse_terminated;
    if let Ok(meta_list) = parser.parse(args) {
        for meta in meta_list {
            match meta {
                // Existing attribute parsing...
                
                syn::Meta::NameValue(nv) if nv.path.is_ident("generate_dual") => {
                    if let syn::Lit::Bool(lit_bool) = nv.lit {
                        attrs.generate_dual = lit_bool.value;
                    }
                }
                syn::Meta::NameValue(nv) if nv.path.is_ident("dual_name") => {
                    if let syn::Lit::Str(lit_str) = nv.lit {
                        attrs.dual_name = Some(lit_str.value());
                    }
                }
                syn::Meta::NameValue(nv) if nv.path.is_ident("verify_duality") => {
                    if let syn::Lit::Bool(lit_bool) = nv.lit {
                        attrs.verify_duality = lit_bool.value;
                    }
                }
                syn::Meta::NameValue(nv) if nv.path.is_ident("dual_documentation") => {
                    if let syn::Lit::Bool(lit_bool) = nv.lit {
                        attrs.dual_documentation = lit_bool.value;
                    }
                }
                _ => {
                    // Unknown attribute - could warn
                }
            }
        }
    }
    
    attrs
}
```

```rust
// In besedarium-macros/src/dual_generation.rs

use crate::protocol_ast::*;

pub struct DualGenerator {
    original_spec: ProtocolSpec,
    attributes: ProtocolAttributes,
}

impl DualGenerator {
    pub fn new(spec: ProtocolSpec, attrs: ProtocolAttributes) -> Self {
        Self {
            original_spec: spec,
            attributes: attrs,
        }
    }
    
    pub fn generate_dual_protocol(&self) -> syn::Result<DualProtocolOutput> {
        if !self.attributes.generate_dual {
            return Ok(DualProtocolOutput::None);
        }
        
        let dual_spec = self.compute_dual_specification()?;
        let original_impl = self.generate_original_implementation()?;
        let dual_impl = self.generate_dual_implementation(&dual_spec)?;
        let duality_proofs = self.generate_duality_proofs(&dual_spec)?;
        
        Ok(DualProtocolOutput::Generated {
            original: original_impl,
            dual: dual_impl,
            duality_proofs,
            documentation: self.generate_dual_documentation(&dual_spec)?,
        })
    }
    
    fn compute_dual_specification(&self) -> syn::Result<ProtocolSpec> {
        let original = &self.original_spec;
        
        // Generate dual name
        let dual_name = if let Some(custom_name) = &self.attributes.dual_name {
            quote::format_ident!("{}", custom_name)
        } else {
            // Default: reverse role order in name
            let roles = &original.roles;
            if roles.len() == 2 {
                quote::format_ident!("{}{}", roles[1], roles[0])
            } else {
                quote::format_ident!("{}Dual", original.name)
            }
        };
        
        // Swap roles in all flows
        let dual_flows = self.compute_dual_flows(&original.flows)?;
        
        // Create dual specification
        Ok(ProtocolSpec {
            name: dual_name,
            attributes: original.attributes.clone(),
            roles: original.roles.iter().rev().cloned().collect(), // Reverse role order
            flows: dual_flows,
        })
    }
    
    fn compute_dual_flows(&self, flows: &[ProtocolFlow]) -> syn::Result<Vec<ProtocolFlow>> {
        let mut dual_flows = Vec::new();
        
        for flow in flows {
            let dual_flow = match flow {
                ProtocolFlow::MessageFlow(msg_flow) => {
                    ProtocolFlow::MessageFlow(MessageFlow {
                        sender: msg_flow.receiver.clone(),
                        receiver: msg_flow.sender.clone(),
                        message: msg_flow.message.clone(),
                        properties: msg_flow.properties.clone(),
                    })
                }
                ProtocolFlow::Choice(choice_flow) => {
                    // For choices, sender becomes receiver and vice versa
                    // Choice becomes Offer, Offer becomes Choice
                    ProtocolFlow::Choice(ChoiceFlow {
                        sender: choice_flow.receiver.clone(),
                        receiver: choice_flow.sender.clone(),
                        message: choice_flow.message.clone(),
                        branches: self.compute_dual_choice_branches(&choice_flow.branches)?,
                    })
                }
                ProtocolFlow::Loop(loop_flow) => {
                    ProtocolFlow::Loop(LoopFlow {
                        body: self.compute_dual_flows(&loop_flow.body)?,
                    })
                }
                ProtocolFlow::Conditional(cond_flow) => {
                    ProtocolFlow::Conditional(ConditionalFlow {
                        condition: cond_flow.condition.clone(),
                        if_branch: self.compute_dual_flows(&cond_flow.if_branch)?,
                        else_branch: if let Some(else_branch) = &cond_flow.else_branch {
                            Some(self.compute_dual_flows(else_branch)?)
                        } else {
                            None
                        },
                    })
                }
                ProtocolFlow::Parallel(par_flow) => {
                    let mut dual_branches = Vec::new();
                    for branch in &par_flow.branches {
                        dual_branches.push(self.compute_dual_flows(branch)?);
                    }
                    ProtocolFlow::Parallel(ParallelFlow {
                        branches: dual_branches,
                    })
                }
                ProtocolFlow::End => ProtocolFlow::End,
            };
            
            dual_flows.push(dual_flow);
        }
        
        Ok(dual_flows)
    }
    
    fn compute_dual_choice_branches(&self, branches: &[ChoiceBranch]) -> syn::Result<Vec<ChoiceBranch>> {
        let mut dual_branches = Vec::new();
        
        for branch in branches {
            dual_branches.push(ChoiceBranch {
                variant: branch.variant.clone(),
                bound_fields: branch.bound_fields.clone(),
                continuation: self.compute_dual_flows(&branch.continuation)?,
            });
        }
        
        Ok(dual_branches)
    }
}

#[derive(Debug)]
pub enum DualProtocolOutput {
    None,
    Generated {
        original: proc_macro2::TokenStream,
        dual: proc_macro2::TokenStream,
        duality_proofs: proc_macro2::TokenStream,
        documentation: proc_macro2::TokenStream,
    },
}
```

```rust
impl DualGenerator {
    fn generate_duality_proofs(&self, dual_spec: &ProtocolSpec) -> syn::Result<proc_macro2::TokenStream> {
        let original_name = &self.original_spec.name;
        let dual_name = &dual_spec.name;
        
        // Generate IsDual trait implementations
        let duality_impl = self.generate_isdual_implementation(original_name, dual_name)?;
        
        // Generate compile-time assertions
        let assertions = self.generate_duality_assertions(original_name, dual_name)?;
        
        // Generate helper types for dual verification
        let helper_types = self.generate_dual_helper_types()?;
        
        Ok(quote! {
            #duality_impl
            #assertions
            #helper_types
        })
    }
    
    fn generate_isdual_implementation(
        &self,
        original_name: &Ident,
        dual_name: &Ident
    ) -> syn::Result<proc_macro2::TokenStream> {
        let original_roles = &self.original_spec.roles;
        
        // Generate IsDual implementations for each role pairing
        let mut isdual_impls = Vec::new();
        
        if original_roles.len() == 2 {
            let role_a = &original_roles[0];
            let role_b = &original_roles[1];
            
            // Generate: IsDual<OriginalProtocol, DualProtocol> for RoleA
            isdual_impls.push(quote! {
                impl ::besedarium::protocol::duality::IsDual<
                    #original_name,
                    #dual_name
                > for #role_a {
                    type Proof = ::besedarium::protocol::duality::DualityProof;
                    
                    fn verify_duality() -> Self::Proof {
                        // Implementation would verify protocol duality
                        ::besedarium::protocol::duality::DualityProof::verified()
                    }
                }
            });
            
            // Generate symmetric implementation
            isdual_impls.push(quote! {
                impl ::besedarium::protocol::duality::IsDual<
                    #dual_name,
                    #original_name
                > for #role_b {
                    type Proof = ::besedarium::protocol::duality::DualityProof;
                    
                    fn verify_duality() -> Self::Proof {
                        ::besedarium::protocol::duality::DualityProof::verified()
                    }
                }
            });
        }
        
        Ok(quote! {
            #(#isdual_impls)*
        })
    }
    
    fn generate_duality_assertions(
        &self,
        original_name: &Ident,
        dual_name: &Ident
    ) -> syn::Result<proc_macro2::TokenStream> {
        if !self.attributes.verify_duality {
            return Ok(quote! {});
        }
        
        let roles = &self.original_spec.roles;
        
        if roles.len() == 2 {
            let role_a = &roles[0];
            let role_b = &roles[1];
            
            Ok(quote! {
                // Compile-time assertion that protocols are dual
                const _: () = {
                    use ::besedarium::protocol::duality::IsDual;
                    
                    // Assert duality relationship exists
                    let _proof: <#role_a as IsDual<#original_name, #dual_name>>::Proof = 
                        <#role_a as IsDual<#original_name, #dual_name>>::verify_duality();
                    
                    let _proof: <#role_b as IsDual<#dual_name, #original_name>>::Proof = 
                        <#role_b as IsDual<#dual_name, #original_name>>::verify_duality();
                };
            })
        } else {
            // For multi-role protocols, generate more complex assertions
            Ok(quote! {
                // Multi-role duality verification would go here
            })
        }
    }
    
    fn generate_dual_helper_types(&self) -> syn::Result<proc_macro2::TokenStream> {
        let original_name = &self.original_spec.name;
        
        Ok(quote! {
            // Helper types for dual protocol reasoning
            pub mod dual_helpers {
                use super::*;
                
                /// Type alias for the dual of the original protocol
                pub type DualOf<P> = <P as ::besedarium::protocol::duality::HasDual>::Dual;
                
                /// Marker trait indicating this protocol has a generated dual
                pub trait HasGeneratedDual {
                    type Dual: ::besedarium::protocol::foundation::GlobalProtocol;
                }
                
                impl HasGeneratedDual for #original_name {
                    type Dual = super::dual_protocol_type; // Would be actual dual type
                }
            }
        })
    }
}
```

### Phase 4: Integration with Main Protocol Macro

```rust
// In besedarium-macros/src/lib.rs - extend the main protocol macro

#[proc_macro_attribute]
pub fn protocol(args: TokenStream, input: TokenStream) -> TokenStream {
    let protocol_attrs = parse_protocol_args(args);
    let input = parse_macro_input!(input as ItemStruct);
    
    // Parse the protocol specification
    let protocol_spec = match parse_protocol_from_struct(&input) {
        Ok(spec) => spec,
        Err(e) => return e.to_compile_error().into(),
    };
    
    // Generate the protocol implementation
    let original_impl = match generate_protocol_implementation(&protocol_spec, &protocol_attrs) {
        Ok(tokens) => tokens,
        Err(e) => return e.to_compile_error().into(),
    };
    
    // Generate dual protocol if requested
    let dual_output = if protocol_attrs.generate_dual {
        let dual_generator = DualGenerator::new(protocol_spec.clone(), protocol_attrs.clone());
        match dual_generator.generate_dual_protocol() {
            Ok(output) => output,
            Err(e) => return e.to_compile_error().into(),
        }
    } else {
        DualProtocolOutput::None
    };
    
    // Combine outputs
    let final_output = match dual_output {
        DualProtocolOutput::None => {
            quote! {
                #original_impl
            }
        }
        DualProtocolOutput::Generated { 
            original, 
            dual, 
            duality_proofs, 
            documentation 
        } => {
            quote! {
                #original_impl
                
                // Generated dual protocol
                #dual
                
                // Duality proofs and assertions
                #duality_proofs
                
                // Documentation
                #documentation
            }
        }
    };
    
    TokenStream::from(final_output)
}
```
