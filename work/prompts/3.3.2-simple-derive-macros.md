# Task 3.3.2: Simple Derive Macros Implementation

## Objective

Implement simple derive macros that build upon the enhanced declarative macro infrastructure from Task 3.3.1, providing ergonomic `#[derive(...)]` syntax for protocol types.

## Background

With Task 3.3.1 completed, we now have a solid foundation of declarative macros (`define_message!`, `define_role!`, etc.) that provide automatic trait implementations. Task 3.3.2 extends this by introducing procedural derive macros that offer an alternative, more idiomatic Rust syntax for the same functionality.

## Requirements

### Core Derive Macros

1. **`#[derive(Message)]`** - Automatic implementation of the `Message` trait
2. **`#[derive(Role)]`** - Automatic implementation of the `Role` trait  
3. **`#[derive(MsgLbl)]`** - Automatic implementation of the `MsgLbl` trait
4. **`#[derive(GlobalProtocol)]`** - Basic protocol trait derivation

### Technical Requirements

- **Procedural Macro Crate**: Create separate `besedarium-derive` crate for proc-macros
- **Foundation Integration**: Work seamlessly with existing foundation types
- **Declarative Compatibility**: Complement (not replace) existing declarative macros
- **Type Safety**: Maintain compile-time verification and type safety
- **Error Handling**: Provide clear, helpful error messages for invalid usage

### Enhanced Features

- **Attribute Support**: Allow customization through derive attributes
- **Field Validation**: Compile-time checks for protocol constraints
- **Documentation**: Auto-generate documentation from derive attributes
- **Performance**: Comparable performance to manual implementations

## Example Usage

### Before (Declarative Macros)

```rust
use besedarium::define_message;

define_message!(LoginRequest {
    username: String,
    password: String,
});
```

### After (Derive Macros)

```rust
use besedarium::Message;

#[derive(Message)]
struct LoginRequest {
    username: String,
    password: String,
}
```

### Advanced Usage with Attributes

```rust
use besedarium::{Message, Role};

#[derive(Message)]
#[message(default, display)]
struct ComplexMessage {
    id: u64,
    data: Vec<u8>,
}

#[derive(Role)]
#[role(display_name = "Authentication Server")]
struct AuthServer;
```
