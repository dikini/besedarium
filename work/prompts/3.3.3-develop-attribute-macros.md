# Task 3.3.3: Develop Basic Attribute Macros

## Objective

Implement foundational attribute macros (`#[protocol]`, `#[role]`, `#[endpoint]`) that provide enhanced syntax for protocol specification while maintaining full integration with the existing type system.

## Background

Building on the derive macro infrastructure from Task 3.3.2, this task introduces attribute macros that transform user-friendly protocol specifications into the underlying session type constructs. This represents the core of the DSL vision, providing natural syntax while preserving type safety.

Attribute macros operate at the item level, transforming entire structs, functions, or modules. The `#[protocol]` macro is the centerpiece, converting natural protocol specifications into proper session type definitions.

## Requirements

### 1. Core `#[protocol]` Attribute Macro

Implement a basic `#[protocol]` macro that supports:

- Role declaration: `roles: Client, Server;`
- Simple message flows: `Client -> Server: Message(data: Type);`
- Linear protocols (no branching initially)
- Property specification for IO and metadata
- Integration with existing foundation types

### 2. Supporting Attribute Macros

Implement complementary macros:

- `#[role]` - Enhanced role specification with metadata
- `#[endpoint]` - Endpoint behavior specification  
- `#[session_type]` - Session type annotations

### 3. Property System

Support multi-level property specification:

- Protocol-level: IO types, metadata, defaults
- Role-level: Specific capabilities, resource limits
- Message-level: Serialization hints, validation rules

```rust
use syn::{parse::Parse, Token, Ident, Type, punctuated::Punctuated};
use quote::quote;

// Protocol specification AST
#[derive(Debug)]
pub struct ProtocolSpec {
    pub name: Ident,
    pub attributes: ProtocolAttributes,
    pub roles: Vec<Ident>,
    pub messages: Vec<MessageFlow>,
}

#[derive(Debug, Default)]
pub struct ProtocolAttributes {
    pub io_type: Option<String>,
    pub metadata_type: Option<String>,
    pub buffer_size: Option<usize>,
    pub timeout_ms: Option<u64>,
}

#[derive(Debug)]
pub struct MessageFlow {
    pub sender: Ident,
    pub receiver: Ident,
    pub message: MessageSpec,
    pub properties: MessageProperties,
}

#[derive(Debug)]
pub struct MessageSpec {
    pub name: Ident,
    pub fields: Vec<MessageField>,
}

#[derive(Debug)]
pub struct MessageField {
    pub name: Ident,
    pub field_type: Type,
}

#[derive(Debug, Default)]
pub struct MessageProperties {
    pub timeout: Option<String>,
    pub priority: Option<u8>,
    pub retry_count: Option<u32>,
}

// Parser implementation
impl Parse for ProtocolSpec {
    fn parse(input: syn::parse::ParseStream) -> syn::Result<Self> {
        // Parse: protocol ProtocolName { ... }
        input.parse::<Token![protocol]>()?;
        let name = input.parse::<Ident>()?;
        
        let content;
        syn::braced!(content in input);
        
        // Parse roles declaration
        content.parse::<Token![roles]>()?;
        content.parse::<Token![:]>()?;
        
        let roles: Punctuated<Ident, Token![,]> = 
            content.parse_terminated(Ident::parse)?;
        content.parse::<Token![;]>()?;
        
        // Parse message flows
        let mut messages = Vec::new();
        while !content.is_empty() {
            messages.push(content.parse::<MessageFlow>()?);
        }
        
        Ok(ProtocolSpec {
            name,
            attributes: ProtocolAttributes::default(),
            roles: roles.into_iter().collect(),
            messages,
        })
    }
}

impl Parse for MessageFlow {
    fn parse(input: syn::parse::ParseStream) -> syn::Result<Self> {
        // Parse: Sender -> Receiver: MessageName(field: Type);
        let sender = input.parse::<Ident>()?;
        input.parse::<Token![->]>()?;
        let receiver = input.parse::<Ident>()?;
        input.parse::<Token![:]>()?;
        
        let message = input.parse::<MessageSpec>()?;
        input.parse::<Token![;]>()?;
        
        Ok(MessageFlow {
            sender,
            receiver,
            message,
            properties: MessageProperties::default(),
        })
    }
}

impl Parse for MessageSpec {
    fn parse(input: syn::parse::ParseStream) -> syn::Result<Self> {
        let name = input.parse::<Ident>()?;
        
        let mut fields = Vec::new();
        if input.peek(syn::token::Paren) {
            let content;
            syn::parenthesized!(content in input);
            
            let field_list: Punctuated<MessageField, Token![,]> = 
                content.parse_terminated(MessageField::parse)?;
            fields = field_list.into_iter().collect();
        }
        
        Ok(MessageSpec { name, fields })
    }
}

impl Parse for MessageField {
    fn parse(input: syn::parse::ParseStream) -> syn::Result<Self> {
        let name = input.parse::<Ident>()?;
        input.parse::<Token![:]>()?;
        let field_type = input.parse::<Type>()?;
        
        Ok(MessageField { name, field_type })
    }
}
```

use protocol::ProtocolSpec;

#[proc_macro_attribute]
pub fn protocol(args: TokenStream, input: TokenStream) -> TokenStream {
    let protocol_attrs = parse_protocol_args(args);
    let input = parse_macro_input!(input as ItemStruct);
    
    // Parse the protocol specification from the struct body
    let protocol_spec = match parse_protocol_from_struct(&input) {
        Ok(spec) => spec,
        Err(e) => return e.to_compile_error().into(),
    };
    
    // Generate the protocol implementation
    match generate_protocol_implementation(protocol_spec, protocol_attrs) {
        Ok(tokens) => tokens.into(),
        Err(e) => e.to_compile_error().into(),
    }
}

fn parse_protocol_from_struct(input: &ItemStruct) -> syn::Result<ProtocolSpec> {
    // For now, parse from doc comments or a specific format
    // This is a simplified approach - a full implementation would
    // parse a DSL syntax within the struct attributes or documentation
    
    // Example: Extract protocol spec from doc comments
    for attr in &input.attrs {
        if attr.path.is_ident("doc") {
            if let Ok(Meta::NameValue(meta)) = attr.parse_meta() {
                if let syn::Lit::Str(lit_str) = meta.lit {
                    let doc_content = lit_str.value();
                    if doc_content.trim().starts_with("protocol") {
                        return parse_protocol_spec(&doc_content);
                    }
                }
            }
        }
    }
    
    Err(syn::Error::new_spanned(
        input,
        "Protocol specification not found in doc comments"
    ))
}

fn parse_protocol_spec(content: &str) -> syn::Result<ProtocolSpec> {
    let tokens: proc_macro2::TokenStream = content.parse()
        .map_err(|e| syn::Error::new(proc_macro2::Span::call_site(), e))?;
    syn::parse2(tokens)
}

fn generate_protocol_implementation(
    spec: ProtocolSpec,
    _attrs: ProtocolAttributes
) -> syn::Result<proc_macro2::TokenStream> {
    let protocol_name = &spec.name;
    
    // Generate message types
    let message_types = generate_message_types(&spec.messages)?;
    
    // Generate role types
    let role_types = generate_role_types(&spec.roles)?;
    
    // Generate protocol types (simplified linear protocol for now)
    let protocol_types = generate_protocol_types(&spec)?;
    
    // Generate trait implementations
    let trait_impls = generate_trait_implementations(&spec)?;
    
    Ok(quote! {
        // Original struct (might be empty placeholder)
        pub struct #protocol_name;
        
        // Generated message types
        #message_types
        
        // Generated role types  
        #role_types
        
        // Generated protocol types
        #protocol_types
        
        // Generated trait implementations
        #trait_impls
    })
}

fn generate_message_types(messages: &[MessageFlow]) -> syn::Result<proc_macro2::TokenStream> {
    let mut message_defs = Vec::new();
    
    for flow in messages {
        let msg_name = &flow.message.name;
        let fields = &flow.message.fields;
        
        if fields.is_empty() {
            // Unit struct message
            message_defs.push(quote! {
                #[derive(Debug, Clone, Copy, PartialEq, Eq)]
                pub struct #msg_name;
                
                impl ::besedarium::protocol::foundation::Message for #msg_name {
                    type Metadata = ::besedarium::protocol::foundation::StandardMetadata;
                }
            });
        } else {
            // Struct with fields
            let field_defs = fields.iter().map(|f| {
                let name = &f.name;
                let ty = &f.field_type;
                quote! { pub #name: #ty }
            });
            
            message_defs.push(quote! {
                #[derive(Debug, Clone, PartialEq)]
                pub struct #msg_name {
                    #(#field_defs,)*
                }
                
                impl ::besedarium::protocol::foundation::Message for #msg_name {
                    type Metadata = ::besedarium::protocol::foundation::StandardMetadata;
                }
            });
        }
    }
    
    Ok(quote! {
        #(#message_defs)*
    })
}

fn generate_role_types(roles: &[Ident]) -> syn::Result<proc_macro2::TokenStream> {
    let role_defs = roles.iter().map(|role| {
        quote! {
            #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
            pub struct #role;
            
            impl ::besedarium::protocol::foundation::Role for #role {
                type Protocol = (); // To be set during protocol definition
            }
            
            impl ::std::fmt::Display for #role {
                fn fmt(&self, f: &mut ::std::fmt::Formatter<'_>) -> ::std::fmt::Result {
                    write!(f, stringify!(#role))
                }
            }
        }
    });
    
    Ok(quote! {
        #(#role_defs)*
    })
}

fn generate_protocol_types(spec: &ProtocolSpec) -> syn::Result<proc_macro2::TokenStream> {
    // Generate session type definitions for each role
    // This is a simplified implementation for linear protocols
    
    let protocol_name = &spec.name;
    let roles = &spec.roles;
    
    // For now, generate placeholder protocol types
    // A full implementation would construct proper session types
    let protocol_defs = roles.iter().map(|role| {
        let role_protocol_name = quote::format_ident!("{}{}Protocol", protocol_name, role);
        
        quote! {
            // Placeholder - would generate actual session types like:
            // type ClientProtocol = TChanSend<Message1, TChanRecv<Message2, TChanEnd>>;
            pub type #role_protocol_name = ::besedarium::protocol::global::TChanEnd;
        }
    });
    
    Ok(quote! {
        #(#protocol_defs)*
    })
}

fn generate_trait_implementations(spec: &ProtocolSpec) -> syn::Result<proc_macro2::TokenStream> {
    let protocol_name = &spec.name;
    
    // Generate GlobalProtocol implementation
    Ok(quote! {
        impl ::besedarium::protocol::foundation::GlobalProtocol for #protocol_name {
            type Roles = (); // Simplified for now
            type Global = ::besedarium::protocol::global::TChanEnd;
        }
    })
}

### Phase 3: Enhanced Attribute Parsing

```rust
#[derive(Debug, Default)]
pub struct ProtocolAttributes {
    pub io_type: Option<String>,
    pub metadata_type: Option<String>,
    pub buffer_size: Option<usize>,
    pub timeout_ms: Option<u64>,
}

fn parse_protocol_args(args: TokenStream) -> ProtocolAttributes {
    if args.is_empty() {
        return ProtocolAttributes::default();
    }
    
    let mut attrs = ProtocolAttributes::default();
    
    // Parse attribute arguments: io = "sync", metadata = "standard", etc.
    let parser = syn::punctuated::Punctuated::<syn::Meta, syn::Token![,]>::parse_terminated;
    if let Ok(meta_list) = parser.parse(args) {
        for meta in meta_list {
            match meta {
                syn::Meta::NameValue(nv) if nv.path.is_ident("io") => {
                    if let syn::Lit::Str(lit_str) = nv.lit {
                        attrs.io_type = Some(lit_str.value());
                    }
                }
                syn::Meta::NameValue(nv) if nv.path.is_ident("metadata") => {
                    if let syn::Lit::Str(lit_str) = nv.lit {
                        attrs.metadata_type = Some(lit_str.value());
                    }
                }
                syn::Meta::NameValue(nv) if nv.path.is_ident("buffer_size") => {
                    if let syn::Lit::Int(lit_int) = nv.lit {
                        if let Ok(val) = lit_int.base10_parse::<usize>() {
                            attrs.buffer_size = Some(val);
                        }
                    }
                }
                syn::Meta::NameValue(nv) if nv.path.is_ident("timeout_ms") => {
                    if let syn::Lit::Int(lit_int) = nv.lit {
                        if let Ok(val) = lit_int.base10_parse::<u64>() {
                            attrs.timeout_ms = Some(val);
                        }
                    }
                }
                _ => {
                    // Unknown attribute - could warn or error
                }
            }
        }
    }
    
    attrs
}
```
